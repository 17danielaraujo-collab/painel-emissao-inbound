Formatos aceitos

1. Base consolidada (cabeçalho agrupado)

  • Linha com o nome de cada cliente (CNH, GMB, IVECO…)
  • Logo abaixo, as colunas VIAGEM e PESO_BRUTO_CTE de cada cliente
  • Uma linha por mês (jan, fev…) até o Total Geral

2. Base analítica (uma linha por registro)

  • Colunas MES, CLIENTE, VIAGEM, PESO_BRUTO_CTE
  • MES pode ser jan, janeiro, 1 ou uma data
  • Se VIAGEM for o código da viagem, o painel conta viagens distintas
